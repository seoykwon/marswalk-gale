### 5-3. EVA control bar off-screen (new, P1-1)

`body.eva` uses `grid-template-rows: auto auto minmax(0, 1fr) auto` for header, warning banner, main and footer. The banner has the `hidden` attribute most of the time, so it is not a grid item. Main then takes row 2 and the footer lands in the `1fr` row with 0 height and overflows below the viewport.

| Viewport | Banner hidden: top of Play button | Viewport height |
|---|---|---|
| 1024×768 | 778 px | 768 |
| 360×640 | 650 px | 640 |
| 390×844 | 854 px | 844 |
| 768×1024 | 1,034 px | 1,024 |

Play, "Turn back now", the time slider and the speed buttons are invisible until a slope warning appears. Compare `work/stage6/evaport_1024x768_none.png` (no bar) with `work/stage5/eva_screens/20_landscape_B_caution.png` (bar present, banner shown). Script 57 missed it because it measures button size, not position.
