## 1. 무엇을 만드는가

화성 게일 크레이터에서 우주비행사가 걸어서 탐사(Marswalk)할 경로를 계획하는 인터랙티브 웹 지도.
여러 NASA 미션의 데이터를 레이어로 겹쳐 보고, 경로를 클릭하면 "이 경로가 사람과 장비에 얼마나 부담되는지"를 한 패널로 요약한다.

- 결과물: GitHub Pages에 올리는 정적 페이지. `index.html` + 타일·자료 파일.
- 화면은 둘이다(2026-11-15 추가). 탐사 전에 쓰는 계획 모드(`index.html`)와, 탐사 중에 보는 EVA 모드(`eva.html`) + 인쇄용 소매 체크리스트(`cuff.html`). EVA 모드는 09 문서.
- 두 번째 목적: 반도체 IT 직무 포트폴리오. 방사선·온도를 "전자부품 영향" 관점으로 해석해 보여준다.

## 4. 용어 설명

### 방사선

| 용어 | 뜻 |
|---|---|
| 흡수선량 (absorbed dose) | 방사선이 물질 1kg에 남긴 에너지. 단위 그레이(Gy) = 1J/kg. 옛 단위 rad는 0.01Gy. |
| 선량률 (dose rate) | 시간당 쌓이는 흡수선량. "방사선의 세기"에 해당한다. RAD 파일의 단위는 µGy/h (시간당 100만분의 1 그레이). 선량률 × 노출 시간 = 누적 선량. |
| 누적 선량 | 일정 기간 동안 쌓인 총 흡수선량. 6시간 탐사라면 선량률 × 6. |
| GCR (은하 우주선) | 태양계 밖에서 날아오는 고에너지 입자. 화성 표면 방사선의 평상시 주성분이며 장소에 따라 거의 변하지 않는다. |
| SPE (태양 입자 폭풍) | 태양 폭발 때 몇 시간~며칠 동안 선량률이 급증하는 사건. 평균값에는 안 보이는 돌발 위험. |
| TID (총 이온화 선량) | 전자부품이 수명 동안 받은 누적 선량. 쌓일수록 트랜지스터 문턱전압이 변하고 누설전류가 늘어난다. 부품 내성은 krad(Si) 단위로 표기한다. |
| SEE (단일 사건 효과) | 고에너지 입자 한 개가 칩을 관통하며 일으키는 오류. 메모리 비트 반전(SEU), 과전류로 인한 래치업(SEL) 등. 누적량이 아닌 확률의 문제다. |
| B 검출기 / E 검출기 | RAD 안의 두 선량 측정기. B는 실리콘 다이오드라 "실리콘이 받는 선량"(전자부품 관점), E는 플라스틱 섬광체라 "인체 조직이 받는 선량"에 가깝다. |

### 지형·지도

| 용어 | 뜻 |
|---|---|
| GeoTIFF | 각 픽셀이 지도상 어느 좌표인지 정보가 함께 들어 있는 이미지 파일. |
| DEM (수치 표고 모델) | 픽셀 값이 밝기가 아닌 고도(m)인 격자 데이터. |
| 경사도 (slope) | DEM의 이웃 픽셀 간 고도 차로 계산한 지면 기울기(도). 보행 위험 판단에 쓴다. |
| 음영기복 (hillshade) | DEM에 가상의 햇빛을 비춰 지형 굴곡을 입체적으로 보이게 만든 그림. |
| 등고선 (contour) | 같은 고도를 이은 선. |
| 가시권 (viewshed) | 한 지점에서 지형에 가리지 않고 직선으로 보이는 영역. 기지와 무선 통신이 닿는 범위의 근사로 쓴다. |
| 타일 (tile) | 큰 지도를 확대 단계별 작은 조각 이미지로 잘라 필요한 부분만 불러오는 방식. |
| Leaflet | 웹 지도를 만드는 가벼운 자바스크립트 라이브러리. |

| 열 사이클 | 낮밤 온도가 오르내리는 반복. 소재마다 팽창률이 달라 납땜 접합부와 패키지에 피로가 쌓인다. |

### 개정 2판에서 추가된 용어

| 용어 | 뜻 |
|---|---|

| LMST | 화성 현지 평균 태양시. 화성의 하루를 24시간으로 나눈 그 지점의 시각. |
| MODRDR / ENVRDR | REMS 자료의 두 등급. MODRDR은 기온·지면 온도·기압 같은 물리량으로 환산한 것, ENVRDR은 센서별 세부값. |
| 신뢰도 플래그 | REMS 센서값마다 붙는 0/1 표시. 자리마다 전원 전압, 로버 정지 여부, 그림자 여부 등을 뜻한다. |
| 열관성 (thermal inertia) | 지표가 열을 머금는 정도. 낮으면(모래·먼지) 낮밤 온도차가 크고 높으면(암반) 작다. |
| 코핀–맨슨 식 | 온도 변동폭이 클수록 납땜 접합부가 적은 횟수에 파손된다는 경험식. |
| 웨이포인트 (waypoint) | 로버가 하루 주행을 마친 지점. sol, 좌표, 고도, 기울기가 기록돼 있다. |
| tilt (기울기) | 로버 차체가 수평에서 기운 각도. 그 지점 지면 경사의 실측에 가깝다. |
| 좌표계 표기 | 파일에 적힌 "이 좌표가 어떤 기준 구·타원체의 것인지"에 대한 정보. 표기가 다르면 같은 숫자가 다른 위치로 해석될 수 있다. |
| VRT | 원본을 복사하지 않고 "어떤 파일을 어떻게 읽을지"만 적어 둔 GDAL의 가상 파일. |
| COG | 필요한 부분만 내려받을 수 있게 내부를 배열한 GeoTIFF. |
| 확대 단계 (zoom, z) | 타일 지도의 배율 번호. 1 올라갈 때마다 2배로 확대된다. |
| GeoJSON | 점·선·면을 좌표로 적은 텍스트 형식. 웹 지도가 바로 읽는다. |
| 숫자 격자 | 고도나 경사 값을 일정 간격으로 나열한 2진 파일. 브라우저가 경로의 고도를 즉석에서 읽는 데 쓴다. |
| THEMIS / TES / MOLA | THEMIS는 Mars Odyssey의 적외선 카메라, TES와 MOLA는 MGS(마스 글로벌 서베이어)의 열분광계와 레이저 고도계. |
| gh-pages 브랜치 | GitHub Pages가 게시하는 전용 가지. 여기에만 타일을 올려 본 저장소가 커지지 않게 한다. |

### EVA 모드에서 추가된 용어 (09 문서)

| 용어 | 뜻 |
|---|---|
| 계획 모드 / EVA 모드 | 계획 모드는 탐사 전에 책상에서 경로를 비교하는 화면(레이어 30개). EVA 모드는 탐사 중에 경로 하나만 따라가며 보는 화면. |
| 되돌아갈 지점 (turnaround point) | "여기서 돌아서야 한도 안에 기지로 복귀한다"는 경로 위의 가장 먼 지점. 시간·일몰·지면 온도·선량 예산 중 먼저 걸리는 조건으로 정한다. |
| 유효 한도 | 위 네 조건을 출발 뒤 경과 시간으로 바꿨을 때 가장 작은 값. |
| 되돌아갈 여유 | 지금 돌아서면 복귀 기한까지 남는 시간. 0이 되면 돌아서야 한다. |
| 여유 시간 (reserve) | 기지에 도착한 뒤 남겨 두는 시간. 가정값. |
| EVA 지점 (station) | 경로를 나눈 중간 기준점. 지점마다 다음 지점의 방위·거리·고도 변화를 적는다. |
| 방위 (bearing) | 북쪽을 0°로 시계 방향으로 잰 진행 방향. 90°가 동쪽. |
| 소매 체크리스트 (cuff checklist) | 아폴로 달 탐사 때 우주복 소매에 차던 작은 수첩. 여기서는 지점별 수치를 적은 인쇄 카드. |
| 재생 (시뮬레이션) | 실제 위치 측정 대신, 계획대로 걷는다고 보고 시간에 따라 위치를 움직여 보여주는 것. |
| 서비스 워커 (service worker) | 웹 페이지와 네트워크 사이에서 요청을 가로채 미리 저장한 파일로 응답하는 브라우저 기능. 네트워크 없이 화면이 뜨게 한다. |
| CSS 픽셀 | 화면 설계의 길이 단위. 표준 환산으로 1/96인치(약 0.26mm). 기기의 실제 화소 수와는 다르다. |
| WCAG | 웹 콘텐츠 접근성 지침. 단추 크기, 글자 대비 등의 국제 기준(W3C). |
| 인쇄 CSS (`@media print`) | 인쇄할 때만 적용되는 화면 꾸밈 규칙. 브라우저의 "PDF로 저장"에 그대로 쓰인다. |
