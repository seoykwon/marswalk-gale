### 1-2. 그리기 동작

- 격자 지연 불러오기: "선 그리기"를 처음 누를 때 `loadGrid()`를 부른다(5MB). 그 전에는 격자 파일 요청 0건, 사용 뒤 2건(고도·경사)으로 확인했다.
- 계산: 꼭짓점 사이를 선을 따라 5m 간격으로 다시 나눈다. 고도는 쌍선형, 경사는 가장 가까운 칸. 구간 경사 = 양 끝 경사 중 큰 값(경로 파일과 같은 규칙, `40_route_profile.py`). 거리는 화성 구(반지름 3,396,190m) 위 거리(`distanceM`).
- 걷는 시간: 구간마다 `길이 / (평지 속도 × 배율)`. 25° 이상 구간은 시간에서 빼고 "통과 불가 n m" 경고를 띄운다. 왕복은 편도의 2배(체류 시간 없음).
- 격자 밖: 양 끝 중 하나라도 격자 밖(또는 nodata)인 구간은 **길이만** 센다. 고도·경사·시간은 없고, "n m(x %)가 격자 밖" 경고, 경사 표의 "격자 밖" 행, 단면 그래프의 보라 띠로 보여 준다. 전부 밖이면 길이만 표시한다.
- "10m 격자 기준 근사" 문구와 한계 설명을 결과 맨 위 상자에 둔다(경사를 재는 크기가 경로 A·B와 달라 구간과 시간이 다를 수 있다는 내용).
- 조작

| 입력 | 점 추가 | 취소 | 마침 | 지우기 |
|---|---|---|---|---|
| 마우스 | 클릭 | "점 취소" | 더블클릭 또는 "마침" | "지우기" |
| 터치 | 탭 | "점 취소" 단추 | "마침" 단추 또는 더블탭 | "지우기" |
| 키보드(지도에 초점) | Enter(지도 중심, 십자선 표시) | Backspace | F 또는 Esc | Delete |

  - 키보드: "선 그리기" 단추에서 Enter를 누르면 초점이 지도로 옮겨 간다. 화살표로 지도를 움직이고 Enter로 점을 찍는다. 십자선은 지도에 키보드 초점이 있을 때만 보인다.
  - 빠른 탭 두 번이 서로 다른 곳이면 더블탭으로 보지 않는다(마지막 두 점이 화면에서 12px 안일 때만 "마침"). 이 오류는 점검 중 발견해 고쳤다(처음에는 빠른 탭이 선을 끝내 버렸다).
  - 그리는 동안 지도 위 다른 레이어는 클릭을 받지 않는다(팝업이 뜨지 않게).
  - 마침 뒤 "선 그리기"를 다시 누르면 같은 선에 이어서 그린다.
- 좁은 화면에서는 그리기 시작 때 시트를 접고(지도 확보), 마치면 반쯤 연다.
- 색: 선은 자홍색에 흰 테두리, 12 문서의 경사 색(노랑–주황–진홍 단계)은 그대로.

### 1-3. 모바일 (1000px 미만)

- 지도가 화면 전체. 패널은 바텀 시트: 접기(손잡이 + 탭 줄, 88px) / 반쯤(46%) / 전체. 손잡이를 누르면 순서대로 바뀌고, 위·아래로 쓸어도 바뀐다. 접힌 상태에서 탭을 누르면 반쯤 열린다. 탭 줄은 가로로 밀린다.
- 레이어 목록은 왼쪽 서랍("레이어" 단추, Esc로 닫기). 지도 컨트롤의 쌓임 순서를 `#map { z-index: 0 }`으로 가둬 서랍 위에 겹치지 않게 했다.
- 상단 줄: 두 줄(71px). 단추 최소 36px.
- 저작권 줄: 한 줄·10px·말줄임으로 시트 바로 위에 붙고(`--sheet-h` 변수), 눌러서 펼칠 수 있다. 지도 면적의 1.1–1.5%.
- 커서 좌표 표시: 터치 장치에서는 숨기고, 좁은 창의 마우스에서는 줌 단추 아래로 옮긴다. 데스크톱에서는 도구줄과 겹쳐 왼쪽 아래로 옮겼다.

## 2. 경로 패널 단추와 주소 매개변수 규약 (EVA·체크리스트가 따를 것)

경로 패널 아래쪽에 "EVA 시작(화성 평균 태양시)" 선택(00:00–23:00, 기본 10)이 있고, 그 아래에 단추 두 개가 있다.

```
eva.html ?route=<A|B> &start=<LMST 시각, 0-23 정수 시간, 기본 10> &season=<Ls 구간 키> &scenario=normal &lang=<en|ko>
cuff.html?route=<A|B> &start=<같음> &season=<같음> &lang=<en|ko>
```

| 매개변수 | 값 | 출처 |
|---|---|---|
| `route` | `A` 또는 `B` | 경로 패널에서 고른 경로 |
| `start` | 0–23 정수. EVA 시작의 현지 평균 태양시(LMST) 시각 | 시작 시각 선택(기본 10) |
| `season` | Ls 30° 구간의 아래 끝 값을 글자로: `"0"`, `"30"`, … `"330"`. 온도 선택과 같은 키 | `state.ls[경로]`, 없으면 `env.js` `DEFAULT_LS`(A `"180"`, B `"240"`) |
| `scenario` | 지금은 항상 `normal` | 고정 |
| `lang` | `en` 또는 `ko` | 현재 화면 언어 |

- 예: `eva.html?route=B&start=10&season=240&scenario=normal&lang=en`, `cuff.html?route=A&start=9&season=180&lang=ko`.
- 단추는 상대 주소(`eva.html`, `cuff.html`)다. 시작 시각이나 계절을 바꾸면 주소가 바로 갱신된다. 언어를 바꾸면 패널이 다시 그려지며 `lang`도 바뀐다.
- 12 문서(1-2절)와 09 문서 300행은 `ls=`와 `scenario=mean`을 썼다. 이번 작업 지시에 따라 `season=`, `scenario=normal`로 바꿨다. **eva.html·cuff.html은 `season`을 읽어야 한다.** 옛 `ls=`는 더 이상 보내지 않는다.
- 페이지가 아직 없으면(HEAD 요청이 404) 그 단추는 `aria-disabled`로 꺼지고 "이 서버에는 아직 이 페이지가 없다"는 안내가 뜬다. 주소(href)는 항상 들어 있다. 점검 시점에는 `eva.html`이 있었고 `cuff.html`은 없어서 체크리스트 단추만 꺼진 상태였다. 두 주소의 매개변수는 주소 문자열로 직접 검사했다(`links.*` 4건 통과).

### 3-3. 그린 선 대 `routes.json` (경로 A, 편도) — 차이를 그대로 적는다

허용 한계는 실행 전에 정했다(거리 1%, 시간 15%, 오르막·내리막 25% 또는 3m, 마우스 클릭 거리 2%).

해석(정직하게)
- **거리는 사실상 같다.** 꼭짓점이 같으면 같은 구 위 거리이므로 당연하다. 클릭 차이 +3.1m는 화면 픽셀 반올림(이 확대에서 1픽셀이 약 0.5m)이 20점에 쌓인 값이다.
- **시간은 10.7% 길게 나온다.** 10m 격자의 경사가 5m 경사보다 5° 근처 값이 더 자주 나와 5–15° 구간(×0.7)이 길어졌다(262m 대 106m). 처음에 "10m 격자는 경사가 매끈해 시간이 짧게 나올 것"이라고 문구를 썼으나 틀려서, 화면 문구를 "길거나 짧게 조금 다를 수 있다"로 고쳤다. 방향은 이 한 경로만으로 일반화할 수 없다(경로 B는 아직 이 방식으로 비교하지 않았다).
- 오르막이 3.0m 대 0.9m로 상대 차이가 크다. 절대 차이는 2m대이고, 10m 평균 DEM이 작은 기복을 지우기 때문이다.
- 경로 A처럼 완만한 경로에서도 시간이 약 11% 달라지므로, 이 도구의 시간은 "대략"이라고 읽어야 한다. EVA 계획의 공식 값은 계속 경로 파일 값이다.

## 5. 알려진 한계

- 10m 격자 값이라 경로 A·B의 5m·2m 값과 구간·시간이 다르다(3-3). 격자 범위(약 15×36km) 밖은 길이만 센다.
- 경사는 가장 가까운 칸 값이라 선이 칸 경계를 지날 때 계단식으로 바뀐다. 구간 경사를 양 끝 중 큰 값으로 잡는 규칙 때문에 경계 근처에서 위쪽으로 치우칠 수 있다(3-3의 시간 증가의 한 원인일 수 있으나 따로 분리해 보지는 않았다).
- 위험 구간 표(15° 이상 띠)는 단면 그래프의 주황 띠로만 보여 주고, 5m·로버 tilt와의 대조는 하지 않는다.
- 그린 선을 저장·내려받기·공유하는 기능은 없다. 새로 고치면 사라진다.
- 손잡이를 위·아래로 쓸어 시트를 바꾸는 코드는 넣었지만, 점검은 탭(손잡이 누르기)만 했다.
- 마지막에 커서 좌표 표시 위치(왼쪽 아래 28px)만 바꾸고 점검은 다시 돌리지 않았다(CSS 한 줄).
- 시트를 끌어서 임의 높이로 맞추는 기능은 없다(세 단계 고정, 쓸기로 이동).
- 점 하나를 끌어서 옮기는 편집은 없다(취소 후 다시 찍기).
- 실제 휴대폰이 아니라 Chrome 터치 에뮬레이션(DevTools 프로토콜)으로 점검했다. 노치·주소창 높이 변화는 보지 못했다.
- 키보드 사용자가 점을 찍는 방식(지도 중심 + Enter)은 정밀도가 확대 수준에 달려 있다.
- 1000px 이상 화면의 도구줄은 지도 오른쪽 위, 커서 좌표는 왼쪽 아래다.
- `cuff.html`이 아직 없어 체크리스트 단추는 점검 시점에 꺼져 있었다(주소만 검사).

## Addendum (2026-11-15, Plan/21 W1): URL contract after the site move

This updates section 2. The rest of the section is unchanged except where noted.

- The planning map moved from `index.html` to **`map.html`**. Its parameters are unchanged:

  ```
  map.html ?route=<A|B> &tab=<route|rad|temp|draw|about>
  ```

  `route` defaults to `B`; an unknown `tab` falls back to `route`.
- `index.html` is now the site home page. If its URL carries `route` or `tab`, an inline script in `<head>` replaces the location with `map.html` plus the same query string and hash (`location.replace`, no extra history entry). So `index.html?route=A` opens `map.html?route=A`, and `index.html?route=A&tab=rad` opens `map.html?route=A&tab=rad`. This also works offline (both pages are in the precache shell). A bare `index.html` (or the site root) stays on the home page.
- `eva.html` and `cuff.html` keep the contract in section 2: `route`, `start`, `season`, `scenario` (EVA only).
- **`lang` is no longer part of any URL.** The site is English only (Plan/19 P1-2): pages ignore `?lang=` and the links never write it. The `lang` row in the table above and the `&lang=` in the examples are obsolete.
- Links back to the map: the "Planning mode" link on `eva.html` and `cuff.html` is now `map.html?route=<A|B>` (static fallback `map.html`).
- Home links (all relative, so they work under a GitHub Pages sub-path such as `/marswalk-gale/`):
  - `map.html`: the "Marswalk" title in the top bar, and a link at the bottom of the About pane.
  - `eva.html`: a "Home" link in the setup dialog. The header band is unchanged.
  - `cuff.html`: a "Home" link on the screen-only bar. It is not printed.
